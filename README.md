# SA-acl-tools

Application Splunk fournissant la commande de recherche personnalisée `editacl`,
qui réécrit en masse les ACL (permissions de lecture/écriture, portée de partage)
d'objets de connaissance Splunk, via l'API REST, à partir d'un pipeline SPL
décrivant l'état cible.
